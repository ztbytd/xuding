# v0.4 · 预算、分析与 CSV 数据迁移

沿用 Electron、React、Ant Design 与本机 SQLite，新增月度预算、支出分析和 CSV 导入导出。首次启动不创建预算或演示账单。

## 月度预算与预测

- 在“支出分析 → 预算设置”配置月份、固定币种、总额度、分类分配与提前提醒阈值（默认 80%）。分类可留空，合计不能超过总额度，未分配额度继续属于总预算。
- 配置后的后续月份自动沿用，关闭应用错过多个月份时补齐相应预算月份；调整某月不会覆盖其他已保存月份。关闭预算保留历史配置，后续月份沿用关闭状态。
- 总览保留三个统计卡片，下面增加紧凑预算进度。切换统计币种不会改变预算币种。
- 本月预测为“本月实际支付 + 本月待确认 + 本月未来尚未生成的预计扣款”。已支付、已跳过或已生成账单不重复进入未来预测。以前月份待确认单独提示，不推断为本月支付。
- 实际支付使用账单自己的汇率或手动历史折算金额；待确认与未来预计使用当前参考汇率。缺少折算时显示已知金额与缺失笔数，完整合计为“—”，暂停依赖完整金额的判断。
- 实际达到阈值与预测可能超额分别展示。桌面预算通知默认关闭，在设置中可独立开启；按实际支付判断总预算与已分配分类预算，达到提前阈值或用尽时通知。一次跨过两个阈值只通知较高阈值，并记录较低阈值已处理。修改预算后重新判断。点击通知打开分析页。

## 支出分析

- 独立菜单提供月份选择、统计币种、预算设置、CSV 导入与导出。
- 查看实际支出、本月预测及预算剩余；历史月份不倒推预测。预算进度使用自己的固定币种。
- 十二个月趋势、分类金额与占比、订阅支出排行可继续查看对应账单，点击订阅可进入详情。
- 账单明细按实际支付日期归属月份；未支付记录按应扣月份归属。支持名称、分类、订阅与状态筛选，确认、编辑与撤销沿用原有账单流程。
- 已归档订阅的支付保留在统计中。没有账单的月份为“暂无记录”，已记录零金额为零；两个月都有记录且上月金额大于零、汇率完整时，才比较已记录支出。

## CSV 导出与模板

- 订阅清单与账单记录分别导出，支持全部或当前筛选结果。分析页提供账单筛选导出，我的订阅提供订阅筛选导出。
- 使用 UTF-8 BOM、CRLF 与带引号字段，兼容 Excel 中文、逗号、换行与引号。对可被表格软件解释为公式的文本加前导单引号，应用再次导入时还原。
- 订阅包含 ID、名称、分类、当前价格、币种、周期、基准日、续费状态、权益日期、网址和备注。
- 账单包含 ID、关联订阅、应扣信息、状态、实际支付、原币与当前选择币种的折算金额及参考日期。
- 图标、完整价格历史和操作审计应使用 JSON 备份；CSV 不等同于完整备份。导入缺少历史汇率时可暂不折算，或明确选用导入时参考汇率，不查询历史日汇率。
- 模板可从导入向导或导出弹窗保存，仓库另提供 [订阅模板](templates/subscriptions.csv) 和 [账单模板](templates/bills.csv)。导入前请替换示例数据。

## CSV 四步导入

1. **选择文件**：支持 CSV / TSV，识别逗号、分号与制表符。自动尝试 UTF-8，失败时使用 GB18030，也可手动切换。上限 10 MB、10,000 条记录、100 列、每格 10,000 字符。
2. **匹配字段**：识别应用模板和常见中英文列名，允许手动映射并设置缺失字段的默认值。年在前的日期支持 `YYYY-MM-DD` 等写法，日/月在前的格式须明确选择 DMY 或 MDY。未知或无效币种、金额、日期与分类不会静默改写。
3. **检查预览**：显示新增、更新、默认跳过与错误数量，可筛选问题行、逐行修正或明确排除全部错误。重复项默认跳过，新增和覆盖需要明确选择。保留行有错误时不能确认。
4. **确认导入**：先保存安全快照，再核对账本修订号并在一个事务中写入。失败不留下半批数据；文件及预览 token 限时有效，重复点击不会重复提交。

订阅有 ID 时优先匹配；没有 ID 时提示同名项，由用户明确选择目标更新或新增。更新价格可指定今天或未来的生效日期，已有账单保留。新订阅从导入当天跟踪，未勾选的历史支付不推断生成。

账单优先按 ID 或已有周期匹配，原币、金额、日期一致的记录提示重复。名称对应多项时须选择具体订阅；没有匹配项时可在行设置中填写新订阅信息，新关联订阅默认关闭自动续费。支付日期不能晚于今天。

提供“历史折算金额 + 币种”时保存手动折算来源，其他币种无法可靠换算时显示待折算。也可明确选用导入时参考汇率，或只保留原币。修改已导入账单的实际金额或币种会使原手动折算失效，改用确认时参考汇率。

导入批次保留来源文件名、时间及处理数量。撤销整批导入时，在备份历史选择对应导入前快照并选“完整恢复整个账本”；该方式会移除快照之外的订阅、账单、预算及导入记录。默认恢复仍按订阅 ID 合并，保留备份之外的记录。安全快照额外保留最近 10 份，应及时另存需要长期保留的备份。
