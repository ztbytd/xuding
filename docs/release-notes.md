续订 v0.8.0

- 新增使用记录、续费决策、取消与权益跟进，可明确开启到期自动归档。
- 总览合并待处理事项，分析解释订阅、价格、周期和汇率变化。
- Ctrl+K 全局搜索、列表筛选排序记忆及快捷操作。
- 可选本地数据库加密、密码与恢复密钥、自动锁定和通知隐私，加密新恢复点。
- 自选 HTTPS WebDAV 加密同步、首次合并预览、离线编辑、并发保护、冲突处理与空间重建。
- 区分同步前保护备份，支持旧明文文件处理，第三方许可随应用提供。

从 v0.5 可在应用内更新，更早版本可手动安装。升级保留账本，加密和同步由用户主动启用。
备份业务格式 v4、数据库结构 5；继续导入旧 v1/v2/v3，旧应用不能读取新账本。
请保存恢复密钥与独立加密备份，本地解锁、同步、旧备份密码分别管理。
同步需要用户自己的兼容 WebDAV 服务，本版支持 Windows 个人多电脑使用。
