# v0.8：订阅决策、安全存储与多设备同步

本版合并 v0.6、v0.7、v0.8 三个里程碑，面向 Windows x64，沿用 Electron、React、Ant Design、TypeScript。离线账本和同步无需续订账号，同步使用用户自己的 WebDAV 服务。

## 使用与续费决策

详情支持今天用过、补记、撤销、近 30 天使用天数、频率、续费决定、备注和评估日期。按订阅/日期唯一，不能记录未来日期。无记录显示“尚无使用记录”，不判断为闲置；开始记录后可选择 30/60/90 天未记录使用提醒。

取消分为尚未申请、已申请、已确认停止续费。申请阶段保留预计扣款；确认后关闭自动续费，保存权益日期，保留历史账单。明确开启自动归档时，在权益结束日期之后运行/解锁应用会归档，仍可通过编辑恢复。撤回决策不自动重新开启续费，恢复续费需在编辑中确认计费安排。取消网址由明确点击打开，应用不会代操作服务商。

评估与取消进度写入详情操作历史。总览合并同一订阅的试用、到期、评估、取消与使用提醒，初始展示四项。列表提供决策/频率筛选、最近更新/名称/下次扣款/月均费用排序及快捷操作。筛选排序记在设备，搜索文字仅保留当前会话。Ctrl+K 搜索支持方向键与回车，新增入口仍在列表和快捷面板。

## 支出变化

总览和分析页区分新增、停止续费、恢复续费、调价及周期调整。当前状态与上月末比较，两期统一用当前参考汇率；有历史汇率时单列旧承诺金额的汇率影响。实际支付差额与月均承诺分开，取消不冲减历史已支付金额。

缺少旧状态、实际支付或汇率时显示“暂无可比数据”，不把未记录历史推断为零。旧版未导出的编辑历史可能不完整，新备份包含订阅状态及参考汇率历史。

## 本地数据库加密

使用 better-sqlite3-multiple-ciphers 13.0.3 / SQLite3 Multiple Ciphers 2.4.0，显式设置 SQLCipher 4 兼容模式（cipher=sqlcipher、legacy=4）。这是 SQLite3 Multiple Ciphers 实现，未冒称 Zetetic 官方 SQLCipher 发行版。N-API 原生模块仅在主进程加载，安装包显式解包。明文账本继续使用 node:sqlite。

随机 32 字节数据密钥通过原生 key(Buffer) 设置，数据库页及 WAL 由引擎加密，临时数据在内存存储。密码保护层使用 scrypt N=32768/r=8/p=1、32 字节盐和派生密钥，以及 AES-256-GCM、12 字节随机 nonce、16 字节认证标签。派生参数固定，封装按本地/恢复/同步用途分别认证。

vault-state.json 只保存密钥封装、选项和受当前密钥保护的旧恢复点密钥。应与数据库一并保留；恢复密钥不能挽救已经丢失的保护描述文件，独立加密备份及其他设备用于这种情况。

启用流程：设置密码 → 保存恢复密钥并输入最后八位确认 → 暂停任务、等待写入/备份 → 截断 WAL 并关闭连接 → 同目录副本加密 → 完整性检查并重新打开 → 原子切换 → 验证后移除旧主库。迁移意图先于副本写入，中断后用密码/恢复密钥解锁会验证并继续，失败保留恢复来源。

修改密码重新封装数据密钥，可用原密码或恢复密钥重设。更换恢复密钥不改变旧备份密码。更换数据密钥重新加密账本并生成新恢复密钥；最多保留八代受保护旧密钥，以读取保留的数据库恢复点。独立账本备份仍用创建时的密码。

开启本地加密后新自动、手动及保护备份必须加密，不静默转明文。若尚无备份密码，向导用新解锁密码配置；已有策略保持原密码。主动导出的普通 JSON/CSV 是明文。

安全页可检查应用备份目录和数据库目录的历史明文备份/恢复点，经原生确认转换或删除。独立备份转换使用备份密码，数据库恢复点用本地数据密钥；故障 WAL/SHM 不当作独立数据库转换。其他位置副本需自行处理，普通删除不保证 SSD 物理擦除。

## 锁定

默认启动解锁、空闲 15 分钟、锁屏与休眠时锁定。空闲支持关闭/5/15/30/60 分钟，托盘后台遵循相同规则；正在提交时先完成该操作再锁定。

锁定关闭数据库、清零可控密钥 Buffer、清除同步基线/冲突和导入预览缓存，重载页面卸载账本和表单，主进程逐请求拒绝账本 IPC。JavaScript 对象/字符串由运行时回收，不宣称彻底擦除内存或系统交换文件。未保存表单需要重新输入。

锁定暂停同步、备份和扣款提醒，解锁后恢复并按去重规则检查提醒。加密开启后默认通知隐藏名称金额，可明确开启；已显示通知在锁定时关闭。可选在当前 Windows 账户记住解锁信息（默认关闭），safeStorage/DPAPI 不防御同一账户下其他程序。凭据不可用时要求手动解锁。

## WebDAV 加密同步

支持用户自选 HTTPS WebDAV 目录与 Basic/应用凭据，拒绝 URL 内嵌凭据和重定向。隔离测试同时配置独立绝对 XUDING_DATA_DIR 与 XUDING_ALLOW_INSECURE_TEST_DAV=1 时只允许回环 HTTP，不开放任意 HTTP 地址。

连接向导测试读取、条件创建、错误版本拒绝、正确版本更新及同版本并发写入，需要强 ETag 和实际原子条件写入。未宣称所有服务商均已验证，兼容性由连接测试检查。凭据仅保存在本机系统保护文件。

首次接入预览本机/远端数量及可能冲突，选择合并或明确替换；替换前保护备份并复核本机修订号。新空间生成随机同步密钥，用独立口令和恢复密钥封装，新设备可用任一加入，本地解锁密码独立。

远端固定文件 xuding-sync-v1.json 的业务快照和设备名称加密。公开头部含格式、随机账本身份及密钥封装，完整头部纳入认证，不能暗中替换口令封装。服务仍可见大小、访问频率及时间。口令更换后，已接入设备提交沿用远端新封装。

业务写入通过 SQLite 触发器在同一事务标记待同步，涵盖账单、预算、CSV、恢复与决策。修改后 10 秒合并提交，解锁运行时每五分钟检查，焦点/恢复按节流检查，也可手动同步。退出不保证网络请求完成，待同步记录保留。

每台设备有独立数据库，以 UUID 修订、祖先关系、上次共同基线进行三方合并，不用设备时间决定覆盖。远端身份改变、已知回退、格式较新、认证失败或密文损坏时保留本地。全新设备不能保证识别所有服务端回滚。

初始上传用 If-None-Match:*，后续用 If-Match:ETag。412/409 最多重新读取合并四次。下载、备份、上传时检查本机修订，保留并再次合并期间修改；全部结果通过完整业务校验。提交结果未知时重试依靠自然唯一键和基线保持幂等。

## 合并、恢复与设备

- 不同订阅及同一订阅无关字段自动合并；金额、币种、周期、间隔、基准日、自动续费、状态及权益日期按关联字段组判断冲突。
- 使用按订阅/日期、周期账单按订阅/应扣日期、价格按订阅/生效日期匹配。实际支付冲突保留双方，不按时间覆盖。
- 删除保留 tombstone；删除/修改冲突交给用户，首版不自动回收删除标记。
- 冲突持久保存在本机数据库（启用加密时加密），可保留本机、采用远端或调整常用业务字段。未解决记录不覆盖远端，无冲突记录继续同步。
- 同步包含订阅、图标、账单、价格、预算、使用、决策及业务历史，不含本机密码、服务凭据、窗口/启动/通知偏好与提醒发送记录。应用同步结果保留本机提醒去重。
- 完整恢复产生新变更，不回退同步修订。同步前保护副本在历史明确标记，与导入/恢复保护合计保留十份，手动备份长期保留。
- 断开保留本地/远端。丢失设备可先同步和处理冲突，再重建空间、更换身份和同步密钥，可信设备重新接入。已下载数据不能收回，可能泄漏的服务凭据需在服务端更换。

初版上限：快照明文 50 MiB、封装 72 MiB、祖先修订 20000 条；达到时提示重建，不静默丢历史。多设备仅支持 Windows 个人使用，移动端和多人协作未交付。

## 兼容、验证与发布

数据库结构 5 新增使用、决策、同步状态和事务待同步表；旧版会拒绝打开，升级前保存一致性恢复点。备份业务 v4 新增 usage、decisions、histories、rateHistory，继续导入 v1/v2/v3，v3/v4 支持完整恢复。设备同步状态、密码和偏好保持本机。加密备份外层仍为 xuding-encrypted v1；旧版不能读取新 v4 业务内容。

v0.5 可应用内更新，更早版本可手动安装。加密和同步由用户开启，不默认上传。Windows Authenticode 未配置，保留 Ed25519 更新清单和 SHA-512 校验。

Vitest 验证决策、取消、旧备份、数据库/WAL/恢复点加密、密码与密钥更换、中断迁移、ETag 并发、离线合并、金额冲突、新口令封装、防回退、保护备份失败及本机通知状态。Playwright 覆盖两台独立桌面实例、连接向导、加密/锁定/重启恢复、搜索、深色和窄窗口。安装包额外检查原生模块、旧库升级及实际 NSIS 更新。

验证均使用虚构账本、隔离 userData 和回环 WebDAV，没有接入真实远端。第三方运行依赖及嵌入加密组件许可由 npm run notices 生成，随应用分发，可从关于页查看。项目源码继续 MIT。
