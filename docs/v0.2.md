# v0.2 日常使用与数据保障

## 后台与提醒

- 首次关闭窗口可选后台运行、退出、取消，并可记住选择；设置中可随时调整。
- 后台运行隐藏窗口并保留托盘，双击恢复；菜单提供打开续订、添加订阅、退出应用。
- Windows 安装版支持开机启动，默认关闭。开启后可选随系统启动时收起到托盘；手动启动正常显示窗口。开发模式不注册系统开机项。
- 通知默认关闭。开启后每分钟检查续费、试用结束及权益到期，并在恢复运行、解锁时检查。
- 续费与试用共用同一账期去重键，兼容旧版本已发送记录；权益按订阅和权益到期日去重。通知显示后记录，发送中也去重，发送失败允许下次重试。
- 权益过期不超过 7 天时可补发一次提醒；更早的已到期记录继续在总览显示。点击通知恢复窗口并进入对应详情。
- 真正退出前等待待处理自动备份完成，再关闭数据库。

## 自动备份与恢复

- 默认开启自动备份，修改订阅后延迟 1.5 秒合并写入当天快照；同日后续修改覆盖当天快照。退出应用会立即处理待写入内容。
- 默认位置为用户数据目录下 `backups/`。选择其他文件夹时在该目录下建立 `xuding-backups/`，新备份保存在新位置，原位置文件保留。
- 自动和应用内手动备份按所选 7/14/30/90 天保留，默认 14 天。恢复前快照额外保留最近 10 份；清理只处理应用规定命名的普通文件，拒绝符号链接。
- 快照先写独立临时文件、同步并关闭，再重命名替换目标，避免半写入文件替代有效备份。
- 设置展示最近成功时间、等待状态和失败原因，支持立即备份及历史抽屉。手动导出的 JSON 文件由用户自行管理。
- 导入或从历史恢复时完整验证 JSON、日期、金额、图标和 ID，展示新增/覆盖/保留数量。预览持有已验证快照，不在确认时重新读取可能被替换的源文件。
- 确认恢复前先保存当前账本快照；快照失败则停止恢复。若预览后账本发生变化，要求重新预览。预览 10 分钟过期，确认成功后令牌失效。
- 导入按 ID 合并，保留未包含在备份内的其他订阅。导入过程使用数据库事务。

## 权益到期

- `accessEndsOn` 为可选的日历日期，旧记录和旧备份可省略，不推算到期日。
- 关闭续费时显示到期日输入，已有到期日始终可编辑。重新开启续费不删除已记录日期。
- 关闭续费只停止扣款预测；权益可继续保留至记录日期。到期当天显示“今天到期”，次日起显示已经到期，不自动归档。
- 列表和详情展示权益日期及剩余天数。总览的“需要关注”集中展示 7 天内试用结束、7 天内权益到期及尚未归档的已到期权益。

## 升级与验证

- 版本 1 SQLite 数据库可直接升级至版本 2，订阅、图标、提醒去重记录与汇率缓存保留；旧偏好自动补齐默认值。
- JSON 备份格式仍为 v1，含新权益日期的备份需使用 v0.2 或以上应用读取。
- 单元验证覆盖旧库升级、权益边界、提醒候选与去重键、日快照合并、保留期、恢复前快照、过期预览和备份失败时停止恢复。
- Electron 验证覆盖实际窗口后台隐藏/恢复、通知事件去重与详情跳转、权益表单与展示、备份历史与恢复、重启持久化。测试使用隔离数据目录并替换通知投递，避免发送真实系统通知。
- 安装版开机项验证替换系统注册调用，检查参数与偏好，不修改开发者电脑的真实开机项。
